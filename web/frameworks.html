Frameworks

Each framework runs in its own isolated environment with a hard wall-clock budget. Install state, OS support and per-framework notes are shown as they are.

Install / repair

Missing environment? Build or rebuild it:

python scripts/setup_envs.py --framework <id>

Platform notes

Auto-sklearn is Linux-only (use WSL2 or Docker on Windows). H2O needs a JVM (java -version). NaiveAutoML is labelled experimental.

Fair-run rules

Every framework gets the same folds, seed and budget (+grace). Failures and timeouts are recorded as results — never dropped.
